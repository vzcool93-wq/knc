# KNC — рабочее приложение команды Keer Noon Club

PWA для команды, которая готовит и развозит еду (Лиссабон). Сейчас фаза тестирования, пользуется в основном один человек — владелец репозитория (курьер/повар). Интерфейс и общение — **на русском**.

- Рабочий адрес: https://vzcool93-wq.github.io/knc/ (GitHub Pages, ветка `main`, корень)
- Установка: Chrome → «Установить приложение» (Android и ПК)

---

## ⚠️ Главное правило: никаких персональных данных в коде

Репозиторий **публичный**. В код, комментарии, плейсхолдеры, тесты и коммиты НЕЛЬЗЯ класть:
имена/ники клиентов, адреса, коды домофонов, код парковки, координаты парковки, Telegram начальника, техкарты компании, списки фасовки.

Все данные живут **только на устройстве** (localStorage) и попадают туда через импорт JSON-файлов, которые владелец хранит у себя. Плейсхолдеры — нейтральные («Мария», «Например: …»).
Перед каждым коммитом — проверка `grep` на имена/коды из реальных файлов данных (сами файлы в репо не кладутся).

## Структура

| Файл | Что это |
|---|---|
| `index.html` | **Всё приложение**: HTML + CSS + JS в одном файле (~1600 строк). Скрипт в одном блоке `{ … }` в конце `<body>`. |
| `sw.js` | Service worker: network-first, офлайн из кэша. **При каждом изменении поднимать версию** `const CACHE = "knc-vN"` (сейчас `knc-v17`), иначе телефоны не обновятся. |
| `manifest.json` | PWA-манифест, тема `#64001b`. |
| `icon-192.png`, `icon-512.png` | Иконка «KNC» (бордовый фон, кремовый текст). |
| `.nojekyll` | Отключает Jekyll на Pages. |

Внешних зависимостей и запросов **нет** (системные шрифты, без CDN) — приложение никуда не отправляет данные.

### Дизайн
- Цвета компании: бордовый `#64001b` (шапка), кремовый `#f3ece0`. Цветовая кодировка действий:
  синий = адрес/навигация, жёлтый = код домофона/постоянная заметка, зелёный = минуты/готово, оранжевый = «Я на месте»/парковка, чёрный = «Доставлено», фиолетовый = заметки на день, розовый = заметка «на сегодня» для клиента, красный = замены в фасовке.
- Светлая/тёмная тема через `light-dark()`.
- Анимации мягкие (`cubic-bezier(.22,1,.36,1)`), FLIP-анимация списка, уважение `prefers-reduced-motion`.
- Звуки — WebAudio (`chime`, `whoosh`), конфетти — `confetti()` / `bigCelebrate()`.
- Кнопки ≥ 44px, всё важное — одной рукой.

## Вкладки (нижняя панель, порядок: Кухня → Фасовка → Доставка)

Переключение — `switchTab(t)`, последняя вкладка в `localStorage["knc-tab"]`.

### 🍳 Кухня (техкарты)
- Список техкарт → техкарта: порции (− / + / ввод, «как в карте»), ингредиенты с галочками (нетто + брутто), шаги, справка.
- **Пересчёт**: `factor = порции / recipe.base`, пересчитываются и ингредиенты, и числа внутри текста шагов.
- **Режим готовки** (`kCook`): один шаг на экран, «Готово, дальше →», прогресс, Wake Lock (экран не гаснет), продолжение с последнего шага.
- **Таймеры**: кнопки в шаге, несколько одновременно, полоса `#timers` сверху (sticky) на любой вкладке, `+1 мин`, звон + вибрация до подтверждения, считают от времени окончания (переживают закрытие). Важно: DOM таймеров обновляется на месте, без пересоздания кнопок (иначе теряются нажатия).

### 📦 Фасовка
- Вставка текста списка (или из файла недели) → разбор `parsePack(text)`.
- Виды «👤 По клиентам» / «🍱 По блюдам», общие галочки, «✓ Всё собрано», счётчики, конфетти при сборе клиента.
- Метка 🚗 N, если имя клиента есть в маршруте доставки.
- Проверка количеств: число в конце строки сверяется с суммой по именам (допускается «без замен» и «вместе с заменами»), иначе предупреждение.
- «✏️ Изменить список» сохраняет галочки у неизменившихся позиций; «🆕 Новый список».

### 🚗 Доставка
Фазы рейса (`state.run`):
1. **Подготовка** (`run = null`): плашка кода парковки (✏️ редактирование → `SETTINGS.parkCode`), блок «📝 На сегодня» (заметки), подсказка, список клиентов, кнопка «🚀 Начать доставку · N».
2. **Доставка** (`run.start`, нет `run.end`): компактный экран «на один экран» (`body.going`), карточка следующего клиента:
   - номер в маршруте, 📌 заметка на сегодня, ⋯ редактирование клиента;
   - адрес → навигация Google Maps (`navLink`, координаты из `!3d…!4d…` если есть), 📍 карта;
   - заметки дня, относящиеся к клиенту (сопоставление имени латиница/кириллица/падежи — `tasksFor`);
   - постоянная заметка (коды подсвечиваются `hl()`);
   - превью сообщения + 🔀, кнопки минут 3/5/7/10/13/15 — копируют текст и открывают Telegram `tg://resolve?domain=…&text=…` (WhatsApp `wa.me` для `+номеров`). Telegram подставляет текст только если был закрыт — поэтому текст всегда ещё и копируется в буфер;
   - «🏁 Я на месте» (короткие варианты), «💬 Чат», «✓ Доставлено».
   - Внизу «⏹ Закончить доставку сейчас».
3. **Все доставлены**: «🅿️ Еду на парковку» (засекает `run.parkStart`, открывает навигацию на парковку) или «Завершить без парковки» → «🏁 Завершить доставку» (`run.end`).
4. **Итоги**: общее время, по клиентам, среднее, лента отрезков (самый долгий подсвечен), стоянка, дорога на парковку, «📋 Отчёт» (текст в буфер), история последних рейсов (`knc-runs-v1`), «🆕 Новая доставка».

Список маршрута: порядок — удержание ~0,4 с и перетаскивание (FLIP, вибрация); ✓ в списке = убрать из маршрута на сегодня (звук «вуш»); «Доставлено» = остаётся на месте со своим номером (`state.done`, `state.doneAt`). Отмена последнего действия — тост «Отменить» (`remember()` / `undo()`).
Заметки на день (`state.tasks`): добавление через модалку `inputBox`, выполнение — **удержанием 0,6 с** (`[data-hold]`), отмена через тост.
Шапка: «KEER NOON CLUB» + кнопка «💬 <начальник>» (из `SETTINGS.bossTg`).

## Хранилище (localStorage, только на устройстве)

| Ключ | Содержимое |
|---|---|
| `contacts-list-v1` | массив клиентов (см. формат ниже) |
| `contacts-state-v1` | состояние доставки: `order[]`, `hidden[]` (убраны из маршрута), `done[]`, `doneAt{name:ts}`, `doneDay`, `run{start,parkStart,end}`, `today{name:{text,date}}`, `tasks[{id,text,done}]`, `trip` |
| `knc-settings-v1` | `{parkCode, parkLat, parkLng, parkMap, bossName, bossTg}` |
| `knc-runs-v1` | история рейсов `[{date,n,total,avg,park}]` (до 30) |
| `knc-recipes-v1` | массив техкарт |
| `knc-kitchen-v1` | `{portions{id:n}, checks{id:[]}, step{id:i}, done{id:[]}, open}` |
| `knc-timers-v1` | активные таймеры `[{id,label,rid,step,end,dur,ack}]` |
| `knc-pack-v1` | `{text, checks{key:1}, view, open}` |
| `knc-tab` | последняя вкладка |

**Важно:** при загрузке `contacts-state-v1` поля перечисляются явно — добавляя новое поле в `state`, добавь его и в загрузку (был баг с потерей `run`).

## Форматы файлов (импорт кнопками «Загрузить/Восстановить»)

Любая кнопка загрузки понимает любой файл и сама разбирает тип. Контакты грузятся только во вкладке «Доставка».

### Контакты (`knc-kontakty.json`)
```json
{ "app": "knc", "settings": { "parkCode": "…", "parkLat": 0, "parkLng": 0, "parkMap": "…", "bossName": "…", "bossTg": "@…" },
  "list": [ { "name": "Имя в приложении (латиница)", "greet": "Имя в сообщении (кириллица)",
              "contact": "@ник" | "+351…" | ["@ник1", "@ник2"],
              "address": "…", "maps": "ссылка Google Maps", "note": "код домофона, квартира…" } ] }
```

### Техкарты / неделя (`knc-tehkarty.json`, `knc-nedelya-….json`)
```json
{ "app": "knc", "kind": "recipes" | "week",
  "recipes": [ {
    "id": "tk-012", "code": "ТК-012", "title": "…", "meal": "Обед / ужин", "base": 10,
    "portion": "≈ 400 г: …", "time": "≈ 2 ч на 10 порций",
    "sections": [ { "name": "Рагу", "items": [ { "id": "chicken", "name": "…", "g": 1400, "b": 1500, "unit": "шт", "note": "…" } ] } ],
    "steps": [ { "title": "…", "temp": "230 °C, конвекция", "text": "Курицу {chicken} смешать с солью {10}…",
                 "timers": [ { "label": "Курица", "min": 11 } ] } ],
    "info": { "Хранение": "…", "Разогрев (клиент)": "…", "Аллергены": "…" } } ],
  "packing": "текст списка фасовки (формат ниже)" }
```
- `g` — нетто на `base` порций, `b` — брутто (необязательно), `unit` по умолчанию «г».
- В тексте шага: `{id}` — всё количество ингредиента, `{id:b}` — брутто, `{50}` — 50 г на базу, `{3000:мл}` — с единицей. Всё пересчитывается (`renderText`).
- Совпадающие `id` техкарт заменяются, новые добавляются.

### Текст фасовки
```
Название блюда - Имя, Имя x2, Имя - 18
NO ONIONS - Имя x2 - 2          ← строка БЕЗ строчных букв = замена к блюду выше
Блюдо без итога - Имя, Имя x2   ← число в конце необязательно
```

## Как работаем

- Деплой = `git push` в `main` (Pages обновляется ~1 мин). Перед пушем: поднять версию в `sw.js`, проверить отсутствие персональных данных.
- Проверка: `node --check` для скрипта, Playwright (Chrome headless, viewport ~390×740, `has_touch`) — прогон сценариев: импорт, пересчёт, таймеры, фасовка, полный рейс доставки (время подменять через localStorage), скриншоты на ширине телефона.
- Пользователь обновляет приложение: закрыть полностью и открыть снова.
- Отвечать пользователю по-русски, коротко и практично.

## Известные ограничения
- Данные на каждом устройстве свои, синхронизации нет (обмен — JSON-файлами).
- Telegram подставляет текст из ссылки, только если приложение Telegram было закрыто; в «Избранное» — никогда.
- Сигнал таймера и любые фоновые действия работают, пока приложение на экране (ограничение PWA).
- В истории git есть ранний коммит со старой служебной таблицей **имён клиентов** (без ников/адресов). Владелец предупреждён; очистка истории предложена, не выполнена.

## Дорожная карта / открытые задачи

1. **Ссылка отслеживания курьера (следующий шаг).** Supabase (не настроен): таблица `track(token, lat, lng, updated_at, arrive_at, state)`, RPC `push_location(secret, token, …)` (SECURITY DEFINER, проверяет секрет) и `get_track(token)` (возвращает одну строку, без листинга). Страница `t.html#TOKEN` на Pages с картой (Leaflet/OSM). При нажатии минут — к сообщению добавляется ссылка, запускается `watchPosition`; «Я на месте» → статус; «Доставлено» → трансляция останавливается. Ограничение: работает, пока KNC на экране (Google Maps в режиме «картинка в картинке»). Фоновая передача — только через гибридное приложение (Capacitor + background geolocation).
2. **Полноценный Supabase**: вход по коду из письма, список допущенных email, роли админ/команда, общая неделя, общие галочки фасовки, утренние правки у всех.
3. **Навык (skill) Claude «KNC: неделя»** для воскресной сборки меню: формат выше, правила перевода техкарт, скрипт-валидатор (ссылки `{id}`, количества фасовки), эталоны.
4. **Валидация при импорте** с понятными ошибками («ТК-012, шаг 3: нет ингредиента {chiken}») и поле `"format": 1`.
5. Кухня: порции по дням доставки и замены («2 без лука»), экран «что готовить сегодня» (день готовки ≠ день доставки), меню недели 5×3, список закупок.
6. Карта внутри приложения и автоматическое время до следующего клиента (Google Directions / OpenRouteService).
7. Тестовая версия (`/knc-beta/`), автотесты в GitHub Actions, «Что нового», кнопка «Сообщить о проблеме».
8. Google Play — через «внутреннее тестирование» (только для команды); публичный релиз требует 12 тестеров × 14 дней.
9. Техкарты ТК-011, ТК-017, ТК-020 ещё не переведены в формат (в ТК-017 нужно уточнить: свиная шея или лопатка; в ТК-020 перепутаны поля шапки и нетто сахара).
